## About

I'm a **Senior Full Stack Developer based in Bangladesh** with experience building SaaS products, eCommerce platforms, AI applications, mobile apps, and internal business systems used in production.

My strongest area is **backend architecture and system design**, but I prefer owning the whole product — from translating requirements into architecture to writing the code, deploying it, and keeping it healthy in production.

I also lead a small engineering team, review architecture and code, and help turn ambiguous product requirements into shippable systems.

```text
Product idea
    ↓
Architecture & system design
    ↓
Frontend + backend + integrations
    ↓
Cloud infrastructure & CI/CD
    ↓
Production · monitoring · iteration
```

## Selected projects

### qCommerz

**Multi-tenant eCommerce SaaS for Bangladesh**

Built around local commerce workflows: storefronts, order management, courier integrations, payment gateways, fraud prevention, analytics, employee management, and tenant-aware customization.

**Stack:** Next.js · Express.js · MongoDB · Redis · AWS · Cloudflare

### eFraudChecker

**Fraud detection platform for online sellers**

A practical risk-analysis product for Bangladeshi merchants, available across web, browser extension, WordPress, and mobile channels.

**Stack:** Next.js · TypeScript · Node.js · Express.js · MongoDB

### DevPilot

**Developer tooling for multi-service workspaces**

A CLI focused on making repetitive development workflows consistent across projects — install, development, build, lint, clean, doctor, and update.

**Stack:** Node.js · TypeScript · CLI tooling

→ [GitHub](https://github.com/cbHasib/devpilot)

### Salaf EMS

**Multi-tenant eCommerce infrastructure**

Working on tenant resolution, customizable storefront architecture, integrations, custom domains, automatic SSL, and deployment workflows.

**Stack:** Next.js · Node.js · MongoDB · Cloudflare · Docker
